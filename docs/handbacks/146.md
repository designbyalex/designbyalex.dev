  Encode command: `ffmpeg -framerate 30 -i <dir>/%04d.png -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -movflags +faststart -an <out>.mp4`.
- **Playback:** the still paints first. The intro plays once, then two copies of the idle hand off to each other so the loop never stalls; portrait files play below 1024px. Sequencing was verified in visible Chrome on 2026-11-12 (still at 26 ms, intro at 0.5s, idle at 2.52s, loop every 6.95s). That code is unchanged since. On 2026-11-13 the media changed: wide (1440) and portrait (390) files load and decode with no errors, muted, `playsinline`, with the grid-free poster.
- **Reduced motion:** the server HTML carries no `<video>`. The still is at rest from first paint, and no MP4 loads (verified 2026-11-12, code unchanged).
- **Seams** (frame RMSE; one frame of mid-idle motion is about 600–700): intro → idle 5.2 wide / 13.0 portrait; loop 7.8 / 9.6.
- **AA over every clip frame:** white text against the brightest background pixel under its glyphs. The scrims were modelled from the CSS, and the model matches live captures over the still within 0.05:1.
